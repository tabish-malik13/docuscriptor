# DocuScripter

- Use self-hostable open-source software with no mandatory paid features, SaaS subscriptions, or commercial add-ons. Prefer permissive licenses and verify package and container component licenses before adopting dependencies. Keep the application proprietary and preserve applicable third-party notices.
- Keep identity, DOCX generation, and PDF conversion separately deployable. The web app uses the gateway for document operations. Keep processing services on a private network.
- Keep the workspace free of seeded demo records and fabricated identities. Require verified authorization for every backend processing request.
